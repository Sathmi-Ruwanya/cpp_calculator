# C++ Calculator CLI

## 📌 Description

This is a simple Command Line Interface (CLI) calculator built using C++.
It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

---

## 🚀 Features

* Add two numbers
* Subtract two numbers
* Multiply two numbers
* Divide two numbers
* Menu-driven system
* Handles division by zero

---

## 🛠️ Technologies Used

* C++
* Notepad (for coding)
* Command Prompt (CMD) for compiling and running

---

## ▶️ How to Run (Notepad + CMD)

### Step 1: Create File

1. Open Notepad
2. Paste the C++ code
3. Save as:

   ```
   main.cpp
   ```

---

### Step 2: Open CMD in Folder

1. Go to the folder where `main.cpp` is saved
2. Click on the address bar
3. Type:

   ```
   cmd
   ```
4. Press Enter

---

### Step 3: Compile the Program

Type this command in CMD:

```
g++ main.cpp -o calculator
```

---

### Step 4: Run the Program

```
calculator
```
